Instructions

  1. The test has 4 parts. In parts 1–3 the questions start easy and gradually get harder. Nobody is expected to get them all right.
  2. Each question has only one best answer. Circle the letter A, B, C or D.
  3. Parts 1–3 have no time limit. Work at your normal pace; there is no need to hurry. (The tester only notes the time.)
  4. If you are not sure, make your best guess. Don’t leave any question blank.
  5. You may use scrap paper. No calculators or phones.
  6. A question like “bird : fly = fish : ?” means: find the word that relates to “fish” in the same way that “fly” relates to “bird”.

Read the passage, then answer questions 11–12.
In one study, people who drank 2–3 cups of coffee a day lived longer, on average, than people who did not drink coffee. However, the coffee drinkers in this study also tended to have higher incomes and to exercise more regularly than the non-drinkers. So the researchers could not yet conclude that coffee really makes people live longer.

  4. D.Regular exercise has no effect at all on how long people live.

How to do it: The key shows which number goes with each shape. In the empty box under each shape, write the number that goes with it. Work from left to right, row by row, as quickly and accurately as you can. Don’t skip any boxes. If you make a mistake, don’t rub it out; just write the correct number next to it.
